1. AR-Theme.bat
Windows Theme Manager [ar.pkyt Edition]
A lightweight, high-performance utility designed to instantly switch between Windows Dark and Light modes with a single click, featuring a sleek cyber-aesthetic interface and built-in support channel.
Features
Instant Mode Switching: Effortlessly toggle between Windows Dark and Light modes.
Auto Explorer Refresh: Automatically restarts Windows Explorer so theme changes apply instantly without requiring a full PC reboot or sign-out.
Secure & Lightweight: No background services or heavy bloatware.
How to Use
Download or place the program file on your computer.
Double-click to launch the application.
Select your desired option from the menu:
Toggle Theme: Instantly flips your Windows theme between Dark and Light.
Support: Displays developer contact and community details.
Exit: Closes the program safely.
